# Legacy Migration Rules

A legacy idea may enter current canon only through this process:

1. Identify the exact legacy element.
2. Explain why it serves the current franchise.
3. Check it against all current character biographies, season arcs, and Book One continuity.
4. Remove any attached legacy assumptions.
5. Obtain explicit approval.
6. Add the approved version to the relevant canon file and changelog.
7. Record which old source remains quarantined.

Never migrate a whole scene because one sentence, name, or dynamic is useful. Rebuild the current version from current canon.
